📘 How to play & solving tips
  • Rule: fill every empty box so that each row, each column and each bold square has every number exactly once (1–9, or 1–4 in Kids).
  • Tap a box, then tap a number. On a computer you can type numbers and move with the arrow keys.
  • Tip 1: Only one place. Pick a number and look at one square. If that number can fit in only one box there, write it.
  • Tip 2: Only one number. If a box's row, column and square already contain all the other numbers, only one number is left.
  • Tip 3: Use Notes. Write small possible numbers in a box with ✏️ Notes, then rub them out as you learn more.
  • Never guess. Sudoku is pure logic and every puzzle has exactly one answer. No maths is needed, only careful thinking.
